  <section class="projects-section">
    <h2>Software</h2>

    <ul class="project-list">
      <li class="project-row">
        <h3><a href="https://mentorsoutreach.org">Mentors Outreach</a></h3>
        <p>Mentoring program management software. Universities, employers, associations, and community groups use it to run applications, human-reviewed matching, sessions, safeguarding, and reporting. Networking African-Australians runs its Homework Club on it.</p>
        <p class="project-row-meta">Founder · 2019–Present</p>
      </li>

      <li class="project-row">
        <h3><a href="https://services.dzaleka.com/">Dzaleka Online</a></h3>
        <p>News, stories, and service information from Dzaleka Refugee Camp. Recorded 17,952 active users in 2025, and launched an iPhone app with offline reading in July 2026.</p>
        <p class="project-row-meta">Founder · Current</p>
      </li>

      <li class="project-row">
        <h3><a href="https://pay.dzaleka.com/">DzalekaPay</a></h3>
        <p>Everyday digital payments for Dzaleka Refugee Camp. Businesses and organisations collect mobile money and card payments through payment links, QR codes, event tickets, storefronts, and fundraising pages, with refugee or asylum seeker ID accepted for verification.</p>
        <p class="project-row-meta">Builder · Current</p>
      </li>

      <li class="project-row">
        <h3><a href="https://github.com/realbakari/ATO-Lens">ATO Lens</a></h3>
        <p>A local-first desktop and web app for exploring Australian tax history, Superannuation Guarantee compliance, and HECS repayments with zero telemetry and private offline processing.</p>
        <p class="project-row-meta">Open source · 2026–Present</p>
      </li>

      <li class="project-row">
        <h3><a href="https://github.com/realbakari/capsule">Capsule</a></h3>
        <p>An open-source agent control plane in Python for governed, replayable execution. Indexes workspace skills, routes tasks with precision, and enforces deny-by-default policy gates.</p>
        <p class="project-row-meta">Open source · 2026–Present</p>
      </li>

      <li class="project-row">
        <h3><a href="https://github.com/realbakari/Capsule-App">Capsule App</a></h3>
        <p>A local-first desktop workspace for macOS and Windows that gives coding agents like Claude Code, Codex, and Grok Build a home for projects, conversations, diffs, approvals, and Git checkpoints of every turn.</p>
        <p class="project-row-meta">Open source · 2026–Present</p>
      </li>

      <li class="project-row">
        <h3><a href="https://github.com/realbakari/UpDeck">UpDeck</a></h3>
        <p>An unofficial browser dashboard for Up bank customers. Works out what's safe to spend until payday, which subscriptions you're paying for, and what changed this month, all on your device with an encrypted token and no ability to move money.</p>
        <p class="project-row-meta">Open source · 2026–Present</p>
      </li>
    </ul>
  </section>
